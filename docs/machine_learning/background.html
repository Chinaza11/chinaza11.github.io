1  Background

This was the capstone project for a machine learning class I took. The class covered the mathematical foundation of several machine learning models and during the course of the class, I had to build several machine learning models from scratch including principal component analysis (PCA), linear regression, logistic regression, and artificial neural network (ANN) models.

For the capstone project, I was given a dataset by the instructor and had to evaluate the models I built during the course of the class on the dataset. I also had to apply existing Scikit-learn packages that implement these models. This allowed me to validate the results I got using the models I built from scratch by comparing their results to those obtained using Scikit-learn packages.

This class gave me a solid background and introduction to machine learning models.
